# Додаткове завдання: Побудова дерева системних викликів (Syscall Tree)

### 🎯 Мета завдання
Реалізувати механізм візуалізації дерева викликів системних функцій під час виконання довільної програми без використання стандартної утиліти `strace`.

### 🛠 Використані інструменти
Для аналізу було обрано підсистему **perf** (Linux Performance Events). На відміну від `strace`, яка працює через `ptrace` і суттєво уповільнює процес, `perf` використовує точки трасування ядра (tracepoints), що дозволяє отримувати дані з мінімальними накладними витратами та повною ієрархією стеку викликів (Call Graph).

### 🚀 Етапи реалізації

1. **Компіляція програми**:
   Програма компілюється з прапорцем `-g` для збереження таблиці символів, що необхідно для відображення назв функцій замість адрес пам'яті.
   ```bash
   gcc -g var5.c -o var5_demo 
   ```
