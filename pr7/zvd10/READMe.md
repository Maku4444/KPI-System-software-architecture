# Задача 10: Генератор випадкових чисел float

### Опис
Програма генерує випадкові числа з плаваючою комою у двох діапазонах:
1. Від 0.0 до 1.0.
2. Від 0.0 до заданого числа $n$.

### Особливості
Для забезпечення унікальності послідовності при кожному запуску використано `srand(time(NULL))`.
