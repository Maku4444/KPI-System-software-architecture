# Задача 2: Імітація команди ls -l

Опис
Реалізація аналога команди `ls -l` без використання системного виклику `system()`. Програма використовує `opendir()`, `readdir()` та структуру `stat` для отримання метаданих файлів.

Ключові особливості
- Вивід типу файлу (директорія/звичайний файл).
- Відображення прав доступу у вісімковому форматі (наприклад, 775).
- Вивід розміру файлу в байтах.
