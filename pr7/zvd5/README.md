# Задача 5: Рекурсивний перелік файлів

### Опис
Програма виконує рекурсивний обхід поточної директорії та всіх її підкаталогів, виводячи повні шляхи до всіх знайдених файлів.

### Використані системні виклики
- `opendir() / readdir()`
- `snprintf()` для формування шляхів.
