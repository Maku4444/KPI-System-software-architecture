# Задача 6: Список підкаталогів у алфавітному порядку

### Опис
Програма виводить лише назви підкаталогів у поточній директорії.

### Технічні деталі
Використано функцію `scandir()` з фільтром для перевірки типу `DT_DIR` та стандартним сортуванням `alphasort`.
