# Задача 3: Проста версія утиліти grep

### Опис
Програма шукає вказане слово у текстовому файлі та виводить рядки, що його містять. Використовується функція `strstr()` для пошуку підрядка.

### Запуск

./zvd3 [шукане_слово] [назва_файлу]
