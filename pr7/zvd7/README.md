# Задача 7: Інтерактивне керування правами доступу

### Опис
Програма знаходить усі файли з розширенням `.c` у поточній директорії та пропонує користувачу надати іншим користувачам дозвіл на читання (`read permission`).

### Реалізація
- Використано `chmod()` для зміни прав доступу.
- Інтерактивний режим через стандартний ввід.
