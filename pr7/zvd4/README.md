# Задача 4: Спрощена версія утиліти more

### Опис
Програма виводить вміст файлів з паузою кожні 20 рядків. Для продовження читання користувач повинен натиснути клавішу Enter.

### Особливості реалізації
- Додано перевірку на `NULL` при відкритті файлу для запобігання Segmentation fault.
- Підтримка декількох файлів як аргументів командного рядка.
