# Задача 8: Інтерактивне видалення файлів

### Опис
Утиліта для безпечного видалення файлів у поточній директорії. Перед видаленням кожного файлу програма запитує підтвердження у користувача.

### Системні виклики
- `unlink()` для видалення файлів з файлової системи.
