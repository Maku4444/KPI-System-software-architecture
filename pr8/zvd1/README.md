# Завдання 8.1: Дослідження часткового запису (`partial write`)

### Опис завдання
Демонстрація ситуації, коли системний виклик `write(fd, buffer, nbytes)` повертає значення, відмінне (менше) від очікуваного `nbytes`. 

### Пояснення
Така поведінка відтворюється при записі у неблокуючий канал (pipe), коли розмір даних перевищує вільне місце в системному буфері ядра Linux (зазвичай 64 KB). Програма намагається записати 1 МБ даних, але `write` записує лише те, що поміщається, і повертає фактичну кількість байтів.
