# Завдання 8.4: Розгалуження процесів (`fork`)

### Опис завдання
Програма демонструє базове використання системного виклику `fork()`, який створює точну копію поточного процесу.

### Аналіз результату
Після виклику `fork()` утворюються два процеси, кожен з яких виконує наступний після нього виклик `printf`:
1. **Батьківський процес** отримує PID створеного нащадка і виводить його на екран.
2. **Дочірній процес** отримує значення `0` і виводить його.
Порядок виводу залежить від системного планувальника завдань (scheduler).
