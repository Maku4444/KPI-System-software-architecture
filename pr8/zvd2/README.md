# Завдання 8.2: Позиціонування у файлі (`lseek` та `read`)

### Опис завдання
Програма демонструє роботу з файловим вказівником. Створюється файл із заданою послідовністю байтів: `4, 5, 2, 2, 3, 3, 7, 9, 1, 5`.

### Логіка роботи
Системний виклик `lseek(fd, 3, SEEK_SET)` переміщує вказівник на зміщення 3 (тобто на 4-й елемент масиву, оскільки індексація починається з 0). Наступний виклик `read(fd, &buffer, 4)` зчитує рівно 4 байти, починаючи з цієї позиції.

Очікуваний результат: `2, 3, 3, 7`.
