# Завдання 8.3: Аналіз швидкодії та тестування `qsort`

### Опис завдання
Дослідження роботи стандартної бібліотечної функції `qsort()` у C. Програма автоматично генерує різні масиви (випадковий, відсортований, у зворотному порядку, з однакових елементів) і рахує кількість порівнянь.

### Висновки аналізу
У процесі дослідження встановлено, що реалізація `qsort` у `glibc` має глибоку оптимізацію:
- Для випадкових даних кількість порівнянь відповідає складності $O(N \log N)$.
- Масиви з однакових елементів та вже відсортовані масиви обробляються значно швидше завдяки внутрішнім евристикам бібліотеки.

Також реалізовано автоматизовані тести для перевірки правильності сортування.
