# Завдання 9.6: Дослідження прав на системні каталоги

### Опис завдання
Програма переглядає права доступу до ключових директорій системи (`~/`, `/usr/bin/`, `/etc/`) за допомогою `ls -ld`, а потім програмно перевіряє доступ до конфігураційного файлу `/etc/passwd`.

### Аналіз прав
1. `~/` (Домашня директорія): Користувач має повні права (`rwx`).
2. `/usr/bin` та `/etc`: Користувач має права лише на читання та виконання (`r-x`), що дозволяє переглядати вміст каталогів та запускати програми, але забороняє зміну або створення файлів.
3. Програмна спроба запису до `/etc/passwd` або спроба його "виконання" блокується ядром ОС, демонструючи базові механізми захисту.
