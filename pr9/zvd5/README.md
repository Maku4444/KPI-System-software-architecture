# Завдання 9.5: Програмна перевірка прав доступу (`access`)

### Опис завдання
Програма створює тимчасовий файл, за допомогою команд `chown` та `chmod` передає його у власність `root` і забороняє доступ іншим користувачам (встановлює права `600`). Після цього програма перевіряє свої можливості щодо взаємодії з файлом.

### Технічна реалізація
Використано системну функцію `access(filename, R_OK | W_OK)`. Вона дозволяє програмі перевірити реальні права доступу ще до спроби відкрити файл через `open()`, уникаючи непередбачуваних помилок. Програма коректно визначає, що доступ їй відмовлено.
