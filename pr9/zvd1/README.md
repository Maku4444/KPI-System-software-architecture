# Завдання 9.1: Аналіз облікових записів (/etc/passwd)

### Опис завдання
Програма зчитує системну базу даних користувачів за допомогою команди `getent passwd` та фільтрує її, щоб знайти лише звичайних користувачів (окрім поточного).

### Архітектурне рішення
Звичайні користувачі в сучасних Linux дистрибутивах (Ubuntu, Debian) зазвичай отримують `UID >= 1000`. Програма використовує `popen()` для отримання виводу команди, розбиває рядки за допомогою `strtok()` і відображає користувачів, які відповідають критерію (виключаючи системні акаунти типу `nobody`).
