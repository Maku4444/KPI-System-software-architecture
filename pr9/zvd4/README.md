# Завдання 9.4: Перевірка стану облікового запису

### Опис завдання
Програма викликає системні утиліти `whoami` та `id` для отримання детальної інформації про поточного користувача.

### Аналіз виводу
Команда `id` демонструє не лише UID та GID користувача, але й повний список додаткових груп (наприклад, `sudo`, `adm`, `cdrom`), до яких він належить. Це важливо для системного адміністрування, оскільки членство в цих групах визначає доступ до специфічних ресурсів ОС.
