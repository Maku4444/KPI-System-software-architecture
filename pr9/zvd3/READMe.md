# Завдання 9.3: Парадокс прав доступу (Зміна vs Видалення)

### Опис завдання
Демонстрація неочевидної поведінки UNIX-подібних систем: права на **зміну** файлу і права на його **видалення** керуються різними механізмами.

### Пояснення результатів
1. **Зміна файлу:** Відбувається помилка `Permission denied`. Файл належить користувачу `root` з правами `644` (звичайні користувачі мають право лише на читання).
2. **Видалення файлу:** Операція успішна. Це відбувається тому, що право на видалення файлу залежить не від атрибутів самого файлу, а від прав доступу до **директорії**, в якій він знаходиться. Оскільки це домашній каталог поточного користувача (де він має право `write` і `execute`), він може видаляти будь-які файли з нього, незалежно від їхнього власника.
