# Завдання 9.2: Отримання адміністративного доступу (sudo)

### Опис завдання
Програма демонструє механізм підвищення привілеїв (Privilege Escalation) через виконання команди `cat /etc/shadow` від імені адміністратора, маючи при цьому права звичайного користувача.

### Особливості
Файл `/etc/shadow` містить хеші паролів і захищений від читання звичайними користувачами. Завдяки утиліті `sudo` та системному виклику `system()`, програма може тимчасово отримати права `root` (за умови, що поточний користувач є у групі sudoers та знає свій пароль).
