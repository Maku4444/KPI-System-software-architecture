# Практична робота 10: Управління процесами (Варіант 5)

### Опис завдання
Реалізувати програму, яка створює дочірній процес. Дочірній процес має завершитися з певним кодом (наприклад, `exit(7)`), а батьківський процес повинен дочекатися його завершення за допомогою `wait()`, отримати цей код і вивести на екран.

### Механізми реалізації
- **`fork()`**: Створення нового процесу.
- **`wait(&status)`**: Призупинення виконання батьківського процесу до завершення дочірнього. Це запобігає появі процесів-зомбі.
- **Макроси POSIX**:
  - `WIFEXITED(status)` — перевірка, чи завершився процес коректно (через виклик `exit` або `return` у `main`).
  - `WEXITSTATUS(status)` — розпакування 8-бітного коду завершення з загального слова статусу, повернутого ядром.

### Результат виконання
